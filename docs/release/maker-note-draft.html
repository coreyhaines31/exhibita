Why it exists

I share marked-up screenshots all day, and so do the agents working on my Mac. Every time it was the same routine: take the shot, open Markup, hunt for the arrow, and still no quick way to hide an email. When an agent wanted to show me something, it couldn’t point at all. So I built the app I wanted: one key per mark, a sentence when that’s faster, and a command an agent can run. And it’s free.

Corey Haines, maker of Exhibit A and more free Mac apps
