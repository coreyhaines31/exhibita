The problem

Pointing at one thing takes too many clicks.

Take the screenshot, click the thumbnail, open Markup, hunt the toolbar for a shape. There’s still no quick way to hide an email before you send it.

Exhibit A opens the capture in place with every tool on one key, finds the text and the secrets in it, and copies the finished image when you press Return.

What it does

Capture, mark, copy.

Every capture is one document: the image, the text and secrets found in it, and your marks. Hand, voice and the command line all write the same marks, and one renderer draws them.

By hand

One key per mark

A for an arrow, C for a circle, B for blur. Click a line of text and the mark snaps to it. ⇧B blurs every detected secret at once.

By voice

Hold D and say it

“Blur the emails and circle pricing.” Speech becomes text on your Mac, and the marks appear where you can still move them.

By agent

One command

An agent runs exhibit on a capture or any image file and gets back a finished PNG and a JSON report.

Marks

Seven marks, one key each.

Press the hotkey, drag a region (Space picks a window, Return takes the whole screen), then mark it up without reaching for a toolbar.

  • AArrow
  • CCircle
  • BBlur
  • HHighlight
  • TText label
  • RBox
  • NNumbered step
  • ⇧BBlur every secret
  • 1–4Colour
  • ⌘ZUndo
  • ↩Copy and close
  • EscClose, kept in history

Blur one email and point at a button: hotkey, drag, B, click, A, drag, ↩.

Hotkeys

Hotkeys that stay out of macOS’s way.

Two global hotkeys, both remappable. Capture and edit opens the editor in place. Capture to clipboard puts the image on the clipboard with no window, and it still lands in history to mark up later.

⌥⇧4 and ⌃⌥⇧4
The defaults while macOS’s own screenshot shortcuts are on.
⌘⇧4 and ⌃⌘⇧4
Where they move once you turn macOS’s shortcuts off. Exhibit A links to that setting and never changes it for you.
Voice

Say what to change.

Hold D, say it, let go. Speech is turned into text on your Mac. Press / to type the same instruction instead.

  • No model needed for plain commands. A built-in grammar knows the seven marks, the kinds of secret and the words on the screen.
  • A local model for the rest, if you want one. Point Settings at a model server on this Mac (Ollama or OpenAI-compatible API, loopback only). It gets your words and a list of what’s on screen, never the image.
  • Never guesses quietly. It names every mark it made and what it couldn’t find. One ⌘Z removes the whole batch.

For agents

One command, a finished image.

The exhibit command marks up a PNG, a JPEG or a capture from the app, writes a new PNG and prints one JSON object. Commands on files need no permissions and make no network calls.

exhibit capture --window "Safari"
exhibit targets shot.png
exhibit blur shot.png --kind email --kind key
exhibit arrow shot.png --to "Update plan" --label "Click here"
exhibit say shot.png "blur the emails and circle pricing"
exhibit mcp
targets

Reads the screen as text

Every line of text, email, key, card number, phone number and face, with its box, as JSON. An agent can find what to mark without image tokens. Secret values never appear in it.

Exit codes

Fails out loud

A selector that matches nothing is a non-zero exit naming it. Several matches for one circle is an error that lists them, unless you ask for all or the nth.

exhibit mcp

MCP over the same commands

A stdio MCP server with tools for targets, marks, a batch of marks, plain words, captures and handing a capture back to you. Add it as command exhibit, argument mcp.

Agent captures are visible: the menu bar icon blinks, history tags the capture “by agent”, and detected secrets are blurred before the agent gets the image. Text read from the screen is labelled as data, not instructions.

Privacy

Your screen stays on your Mac.

No account, no analytics, no server of ours. Captures live in your Library for 30 days by default, outside Time Machine, and one click purges them.

Blur that can’t be undone

Exported files are flat pixels with no layers and no copy of the original. A blur is filled from pixels outside it, so what was under it isn’t in the file.

Never-capture list

Password managers and Keychain Access are never captured, by you or an agent. In a wider capture their windows turn black with a label saying why.

Nothing leaves without you

The update check is the app’s only request of its own; macOS may fetch its speech model once. A model endpoint must be on this Mac.

Questions

Before you install.

How do I get it?

Download the DMG from this page, or run brew install --cask coreyhaines31/tap/exhibit-a. It needs macOS 14 Sonoma or later, and checks for updates itself.

What permissions does it need?

Screen Recording, once, to take captures. The microphone and speech recognition only the first time you hold D. The exhibit command never has or asks for a permission; live captures come from the app.

Can someone recover what I blurred?

Not from an exported file. It’s flat pixels, and the blur is built only from pixels outside the blurred area. In the editor, marks stay editable until you export, so you can still move or remove a blur.

Does voice need the internet?

No. Speech is turned into text on your Mac, never on a server. The first time, macOS may need to download its speech model.

Do I need an AI model?

No. The built-in grammar handles plain commands like “blur the emails” or “circle Pricing”. Free-form requests need a model server you run on this Mac, set up in Settings. Exhibit A only accepts an address on this Mac.

What does an agent get to see?

The capture with detected secrets already blurred (a Settings switch), and text read from the screen marked as data, not instructions. Detection is pattern matching, so it can miss things. Never-capture apps are never in the image.

How long are captures kept?

30 days by default, so marks stay editable. Retention is a setting, including deleting a capture once you export it, and you can purge history at any time.

What does it cost?

Nothing. Exhibit A is free with no account. The source is on GitHub under the Functional Source License (FSL-1.1-MIT), and each version becomes MIT two years after release.
